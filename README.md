# E-Commerce SQL Data Analysis

## Project Overview

This project focuses on analyzing an e-commerce business using MySQL and advanced SQL queries.

The analysis covers customers, orders, products, sales, revenue, purchasing behavior, and business performance. The project is designed to simulate real-world data analysis tasks that a Data Analyst may perform using SQL.

The project includes analytical queries using joins, subqueries, CTEs, window functions, aggregate functions, date functions, string functions, CASE statements, and other SQL techniques.

## Database Structure

The project uses a relational e-commerce database consisting of the following tables:

- **customers** – Contains customer information such as customer ID, name, city, and other customer details.
- **orders** – Contains order-level information including order ID, customer ID, and order date.
- **order_items** – Contains individual items purchased in each order, including quantity and unit price.
- **products** – Contains product information such as product ID, product name, and category.

### Table Relationships

- Customers → Orders: One customer can place multiple orders.
- Orders → Order Items: One order can contain multiple items.
- Products → Order Items: One product can appear in multiple order items.

## Business Analysis

The project answers real-world business questions such as:

- Which customers generate the highest revenue?
- Which products generate the highest sales?
- What are the top-performing product categories?
- Which customers have made multiple purchases?
- What is the monthly revenue trend?
- How does revenue change from one month to the next?
- Which customers have spending above the average?
- What are the top customers within each city?
- Which product categories have the highest monthly revenue?
- How do customer purchasing patterns vary across different cities?
